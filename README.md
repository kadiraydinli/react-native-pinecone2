# React Native Pinecone

Bu React Native UI bileşen kütüphanesi, Trakya Üniversitesi lisans bitirme tez projemdir. 

Yüklemek için aşağıdaki komutu kullanabilirsiniz.

## Kurulum

    yarn add react-native-pinecone
    
    # veya npm ile
    
    npm install react-native-pinecone

Simgelerin çalışması için aşağıdaki paketi projenize entegre etmeniz gerekmektedir.

    yarn add react-native-vector-icons
    
    # veya npm ile
    
    npm install --save react-native-vector-icons

[react-native-vector-icons paketine göz atmak için tıklayın.](https://github.com/oblador/react-native-vector-icons)
